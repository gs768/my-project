# Sutton Digital Marketing — working notes

## Client database

"Client database", "Sutton client database", "client master" and "master sheet"
all mean one Google Sheet:

**Sutton Digital Clients – Master**
https://docs.google.com/spreadsheets/d/1eIhE8_PzK1KsctTlrmjSDzZZvob0xBRXi9QuXMo4zFY/edit
Tab "Clients Master". Row 1 is category headers, row 2 is column titles, client
rows start at row 3.

- Column A: Client Location
- Column I: SEO
- Columns BT–BW: GA4, GSC, Ahrefs, GBP IDs
- Column BX: BrightLocal location ID
- Columns CF–CX: IDs carried over from the retired sheet (NAP project ID,
  practice area, GTM, SEMrush, Majestic, BrightLocal codes, etc.)

"All Clients Core info" (`1gDXN45…`) was retired and deleted on 2026-09-27.
Never use it; its BrightLocal IDs were misaligned on several rows.
