## Contingencies
| If... | Then... |
|---|---|
| Only 1-2 attendees | Run it as planned, shorter Q&A, more personal; network attendees fill the room; still record for replay and ads |
| Gabriel's connection drops | Sam shares PDF backup slides and plays the HeyGen intro video; Gabriel rejoins via phone hotspot |
| A prepared firm isn't present | Use the demo firm (Fox Injury Law / Vinas DeLuca) for the live analysis |
| Someone asks about pricing | "Pricing depends on markets and case types; that's what the audit is for." Book the call |
| A hostile or competitor question | Thank them, answer briefly with Google's own documentation, move on |
| A legal-ethics question (bar advertising rules) | "We follow state bar rules; we'll review yours on the audit call." No legal advice |
| Zoom or Eventbrite link fails | Raghu sends a backup Zoom link by email from Eventbrite; Shereesa posts it on the landing page |
